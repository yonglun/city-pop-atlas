# City Pop Atlas 迭代规划

日期：2026-10-02。目标：从静态图谱升级为可持续维护、可追溯、可扩展的三语音乐资料库。

## 迭代 1：资料库基础与媒体体验（已交付 v0.2）

1. **数据存储**：D1 / SQLite，6 张业务表、必要索引、版本化 schema 迁移；资料快照原子导入，失败回滚，删除错误资料后不会残留旧关系
2. **对象与属性**：保留稳定 ID、三语标题与简介；增加生日、出生地、身份、乐器、发行日期、曲序、版本等带来源属性；属性定义表允许新增字段，现有前端可通用展示
3. **资料采集**：将原数据统一为可编辑 JSON；以官方唱片资料补全 SUNSHOWER 等作品及逐曲演奏人员；提供基于明确 MusicBrainz ID 的限速采集器，输出待审核候选，不自动混入正式库
4. **可视化**：图谱保持旋转、搜索与筛选；档案卡片和详情加入有许可的人物照片；唱片使用官方播放器展示封面，缺图/未匹配保持明确缺失
5. **音乐链接**：精确 Spotify / YouTube 条目，注明数字扩展版、重制版、官方视频等版本；不将搜索结果页当作精确匹配

### 本次数据成果

原来 106 条目 / 178 关系，增加至 122 条目 / 278 关系。新增 16 条目与 100 条去重后的关系。5 位人物有许可照片，7 个唱片官方播放器，35 条已核实的媒体链接。照片拍摄年份独立于作品年份。覆盖率在站内“资料与收录说明”显示。

### 验收

- 数据库重复读取和进程重启后数据保留
- 重复导入不重复；新版本删除的资料不残留；导入失败不污染旧快照
- 全部条目有三语标题，关系无悬空或重复；每条属性能追溯来源
- 自动旋转、鼠标移入、缩放、暂停/恢复、导航等真实 DOM 事件流回归
- 平台精确链接、来源、图片许可显示；无法获取图片时保留文本入口
- API 不提供匿名写入或任意 URL 代理

## 迭代 2：版本与录音的精细建模（已实现首批 v0.3）

将 Album（专辑概念）、Edition（发行版）、Work（词曲作品）、Recording（具体录音）、Track（唱片中曲目位置）彻底分开；保持旧 URL/ID 适配。

- 首批选择 10 张代表性专辑核实原版 / 再版、厂牌、编号、介质和完整曲目
- 通过 MusicBrainz release-group / release / recording / work、ISRC 建立外部标识
- Spotify 匹配落到具体录音/发行版，不覆盖原始发行年
- 制作人与编曲、演奏职责独立，不把专辑级人员复制到每首歌

验收：至少 10 张专辑有可追溯发行版和完整曲序；现场、混音、重制版本不误合并。资料量由来源可验证性决定，不承诺无证据的“全量”。

当前成果：10张专辑、13个发行版、127曲目位置、38词曲作品和1条录音。仅明确来源支持的身份关系进入图谱；物理版本录音等同性未确认的保持空缺。先交付分层和版本比较，继续补全录音匹配属于后续数据工作。

## 迭代 3：采集审核与规模化（基础审核已实现，规模化后续）

建立候选审核界面、重复实体合并建议、字段差异、拒绝原因、导入历史与撤销方案。采集仍以公开官方接口和可用页面为准，遵守来源限速、条款与版权条件。

- 已确认 ID 优先；模糊搜索只给候选与置信解释
- 每个断言记录来源、抓取时间、审核状态和冲突
- 外部链接失效/地区差异按实情标记，保留原证据
- 当前不启动无人值守定时抓取；定时频率和范围另行确定

验收：重复导入无重复，失败可重试；候选未经审核不会进入正式资料。

## 迭代 4：更完整的视觉档案

继续补充可再利用的人物图片；封面优先官方播放器或明确授权来源。若要托管获授权图片，再增加对象存储及版权元数据，不默认搬运整站图片。

- 原版与再版封面和图片日期分别记录
- 来源、作者、许可、裁剪说明可见
- 官方播放器受地区限制时仍能访问对应页面

本轮同时实现了属性级候选导入、对比、批准/拒绝、并发防护、独立持久化覆盖和审核历史；批量实体合并、关系审核、撤销界面及自动调度尚未实现。

## 不在当前范围

无音源/歌词复制，无公开编辑后台，无付费 API，无新 OAuth/API Key，无无人值守定时任务。进一步的跨版本录音匹配、关系审核和规模化导入属于后续迭代。

## 本次续作：可撤销校订 v0.5

- 批准时保存校订前后快照；提供恢复值预览、必填原因和确认/取消
- 撤销仅作用于仍生效的批准；原来源和时间一并恢复，审核历史保留，候选回到待审核
- 逆序撤销、重复请求、重新批准、并发校订、基础资料变化和事务失败均有回归
- 旧版本已批准内容没有快照，不猜测恢复；本版本不增加实体合并或关系编辑
